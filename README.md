# Estética Danielle Bocchi

Site institucional da clínica de estética **Danielle Bocchi**, localizada em Curitiba-PR. Projeto desenvolvido com [Vite](https://vitejs.dev/) e Vanilla JS, utilizando configuração multipage.

## Páginas

- **index.html** — Página inicial
- **servicos.html** — Serviços oferecidos
- **sobre.html** — Sobre a clínica
- **contato.html** — Contato e localização

## Comandos

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build

# Visualizar build de produção
npm run preview
```
